# 차트 입력 형식 (정답 세트용)

정답 차트는 `data/refs/<곡이름>.chart` 텍스트 파일로 저장합니다. 예측 결과도 같은 형식(또는 JSON)이고, `evaluate.py`가 파일 이름으로 짝지어 채점합니다.
**"그 라이브 영상에서 실제로 친 그대로"** 적습니다. 원곡 구성으로 정리하지 마세요.

입력 후 꼭 확인: `python check_chart.py data/refs/<곡이름>.chart` → 실제 연주 순서대로 펼친 마디 목록이 나옵니다.

## 전체 예시

```
Title: 곡 제목 (OO교회 라이브 2025)
URL: https://www.youtube.com/watch?v=XXXXXXXXXXX
Key: G   BPM: 72 (가변)   4/4

[Intro] (free)
| G | Cmaj7 | Em7 | Dsus4 D |

[Verse 1]
| G | D/F# | Em7 | Cmaj7 |
| G/B | C | Am7 | Dsus4 D |

[Chorus] x2
| C | D | Em7 D/F# | G |
| C | D | G/B C | D . . . |

[Key Up → Ab]
[Chorus]
| >Db | Eb | Fm7 Eb/G | Ab |
| Db | Eb | Ab/C Db | Eb (stop) |
```

## 규칙

### 머리말 (맨 위)
| 줄 | 뜻 |
|---|---|
| `Title: ...`, `URL: ...` | 곡 정보 (URL은 나중에 오디오를 받을 때 사용) |
| `Key: G   BPM: 72   4/4` | 시작 키 · 대략 템포 · 박자. 한 줄에 같이 써도 되고 따로 써도 됨. 단조는 `Em` |

### 구간
- `[이름]` 한 줄이 구간 시작. 이름은 자유지만 아래 단어를 쓰면 종류가 자동 인식됩니다(채점에 사용):
  Intro/전주, Verse/V/1절, Pre-Chorus/PC/프리코러스, Chorus/C/후렴, Bridge/B/브릿지, Interlude/Inst/간주, Solo/솔로, Outro/Ending/엔딩, Tag, Break
- `[Chorus] x2` : 이 구간을 2번 반복 (`×2`, `2x`, `2회`도 됨)
- `[Intro] (free)` : 박이 없는 구간(루바토, 프리 인트로). 이 구간은 체인지 타이밍을 마디 단위로만 채점합니다.

### 마디
- 한 줄에 `|` 로 마디를 구분: `| G | D/F# | Em7 | C |` (한 줄에 몇 마디든 자유)
- **한 마디 안 코드 위치**
  - 4/4에서 코드 2개 → 1박, 3박: `| Em7 D/F# |`
  - 4/4에서 코드 4개 → 박마다: `| C G Am F |`
  - 그 외에는 `.` 로 박을 채움 (`.` = 한 박 유지): `| C . . G |` → C 3박, G 4박에서
  - 또는 `@박` 으로 직접: `| C G@4 |`, 반박은 `| C G@2.5 |` (2박 뒷박)
  - 4/4에 코드 3개처럼 애매하면 오류가 나고 위 방식으로 적으라고 알려줍니다.
- `%` : 바로 앞 마디와 같음
- `.` 만 있는 마디: 앞 코드를 계속 유지
- `N.C.` : 노 코드 (모두 쉼)

### 기호
| 기호 | 뜻 | 예 |
|---|---|---|
| `>코드` | **푸시**: 그 코드가 8분음표 하나 먼저 들어옴. 마디 첫 코드면 앞 마디 4박 뒷박에 들어옴 | `| C | >G |` |
| `(stop)` | 스탑 (모두 멈춤) | `| D (stop) |` |
| `(break)` | 브레이크 | |
| `(fermata)` | 늘임 | |
| `코드?` | 정답 입력자도 확실하지 않은 코드 | `| Cmaj7? |` |
| `#` 뒤 | 메모 (앞에 공백 필요. `F#`의 샵과 구분) | `| C |  # 여기서 드럼만` |
| 그 외 `(...)` | 자유 메모 (채점에 영향 없음) | `| D (4박 앞당김) |` |

### 전조 / 박자 / 템포 변화
- `[Key: Ab]`, `[Key Up → Ab]`, `[전조 → Ab]` : 이후 전부 Ab. 구간 사이에 쓰면 **다음 구간부터** 적용
- `[Key +1]`, `[Key +2]` : 반음/온음 위로 (상대 표기)
- `[Time 3/4]` : 이후 박자 변경. 한 마디만이면 `| {2/4} D |`
- `[BPM 80]` : 템포 메모 (채점에는 안 씀)

### 코드 표기
- 근음: `C D E F G A B` + `#`/`b` (이명동음은 같은 음으로 채점: D#m = Ebm)
- 성격: `m 7 maj7(M7, Δ7) m7 sus4(sus) sus2 add9(add2, 2) dim dim7 m7b5(ø) aug 6 69 9 11 13 7sus4 m(maj7) 7b9 7#9 ...`
- 분수코드: `G/B`, `D/F#`
- **확실하지 않은 텐션은 빼고 3화음으로** 적습니다(정답 세트도 같은 원칙).
